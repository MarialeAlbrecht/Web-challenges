# 💻 Web Challenges – Neuefische Bootcamp 2025

This repository contains the **web challenges** completed during the **2025 Web Development Bootcamp at Neuefische**. These exercises were designed to reinforce the concepts learned in class and to provide hands-on practice with web development fundamentals.

---

## 📝 Overview

- The bootcamp followed an intensive, fast-paced schedule. 
- The challenges in this repository were primarily **solo exercises**, allowing for focused practice and independent problem-solving.  
- Due to the pace of the program, I frequently applied **self-directed learning** to supplement class instruction.
